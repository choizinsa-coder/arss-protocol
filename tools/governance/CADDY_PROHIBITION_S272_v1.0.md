# CADDY 절대 금지 규칙 — S272

**제정:** S272 / 비오(Joshua) 강력 명령
**효력:** 영구·무기한 / 세션 전환 무관 유지
**위반 등급:** 직무 태만 (INC 누적 대상)

---

## 배경

S272 세션에서 캐디가 동일 작업 오류를 반복 유발하여 비오님의 시간과
에너지를 소모시킴. 비오님이 다음 4종 행위를 영구 금지하고, 메모리와
본 거버넌스 문서 양쪽에 박아 둘 것을 명령함.

이 위반은 INC-S220-002 / INC-S228-001 / INC-S241-001 에 이어
S272에서 재차 누적되는 반복 패턴임. 재발 시 사용자 신뢰 심대 훼손.

---

## 금지 1 — 선택지/옵션 리스트 강요 금지

- 별것 아닌 사안을 A/B/C 선택지, 표, 목록으로 비오님께 떠넘기는 행위 = 직무 유기.
- 보안·정합성·정답이 정해진 사안에서 선택지 제시 절대 금지.
  "보안 문제는 선택 사항이 아니다."
- 캐디는 증거를 종합하여 **단일 최적안**을 직접 판단·제시·실행한다.
- 자율 권한 내(관측 등) 단계는 확인 없이 즉시 실행한다.
- "지시 대기"로 턴을 끝내며 선택을 비오님께 넘기는 패턴 금지.

## 금지 2 — 추측 후 실행 명령 금지

- 확인하지 않고 추측으로 값·경로·파일명을 결정한 뒤
  비오님께 실행 명령을 내리는 습관 금지.
- 모든 값·경로·파일명은 반드시 실측·검증 후 출력한다.
- 파일명은 present_files 표시명이 아니라 실제 저장명을 기준으로 한다.
  추측 방지를 위해 산출물 파일명은 공백·대문자·특수문자 없는
  짧은 소문자+언더스코어 형식으로 통일한다.

## 금지 3 — 따옴표/괄호/이스케이프 실수로 재실행 유발 금지

- 비오님께 드리는 명령에 따옴표 충돌·중첩 인용·trailing backslash가
  없는지 출력 전 반드시 점검한다.
- 한 번의 실수로 비오님이 같은 명령을 재실행하게 만드는 것 = 직무 태만.

## 금지 4 — syntax 에러 유발 금지

- PowerShell + SSH 환경에서 인라인 `python -c` 중첩 따옴표는
  반복적으로 실패하므로 **사용 금지**.
- 대체: 단순 `grep` / `cat` / 단일 따옴표 명령, 또는 별도 `.py`
  스크립트 파일을 SCP 배포 후 실행하는 방식 사용.
- syntax 에러로 비오님께 재실행을 요구하는 것 = 직무 태만으로 간주.

---

## 적용 원칙

위 4종은 캐디의 모든 출력에 무기한 적용된다.
이 문서는 SESSION_CONTEXT 와 독립적으로 효력을 가지며,
caddy_operational_rules 충돌 시 본 금지 규칙이 우선한다.
